# AgentInbox 0.0.4 launch screenshots

English. The notification inbox of v0.0.4. The web shots come from a release web build talking to a
throwaway local server (seeded mailboxes, three ingest sources, two agent keys); the Android shots come
from the demo build on a Pixel 6 emulator. The persona is fictional: Lin Chen, northwind.dev,
status.northwind.dev. Nothing here is a real account or host, and the `nb_…` tokens belong to a local
test server that no longer exists.

Web shots are 1920×1080; Android shots are a Pixel 6 emulator at 1080×2400. Light and dark
are the app's own themes.

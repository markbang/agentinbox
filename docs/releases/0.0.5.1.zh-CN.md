0.0.5 的修复版：重做后的客户端在真机和宽窗口上出的几个问题——标题不显示、每个页面上方那条浅色横带、字体不对、两个加载圈、列表末尾被标签栏压住，以及密钥、面板和写信页的几处细节。

## 0.0.5.1 包含

### 改进

- 宽窗口下，面板最宽 640 pt 并居中（设置、写信和表单面板变成一张卡片，与 iPad 一致），不再铺满整个宽度。

### 修复

- 各页面重新显示标题：导航栏的标题按滚动值淡入，而没有任何东西驱动这个值，于是一直停在完全透明。
- **Android 重新全面屏**：内容从状态栏之下开始、铺在应用自己的背景上，状态栏图标跟随明暗外观。
  导航栈给每个页面加上的系统工具栏已去掉——它的浅色窗口背景就是那条白带，还把每个页面往下推了 100 pt。
- **字体用平台的**：Android 拉丁字母用 Roboto、中文用 Noto Sans CJK SC，Windows 用 Segoe UI，
  Web 跟随系统，不再是松散的兜底字形；iOS 的字距只在 SF Pro 这款它测量过的字体上生效。
- **只有一个加载指示器**：列表下拉刷新用 Cupertino 的指示器，工具栏旁不再出现系统那个青色 Material 圈。
- **标签栏不再压住列表末尾**：设置等列表停在标签栏上方，不再有一行藏在栏下。
- API 密钥：已撤销的密钥留在列表里，显示为灰色、不可点击并标出撤销日期（服务器本就保留它），不再像还能用一样消失。
- **写信页的定时菜单不再被键盘挡住**：打开菜单会收起键盘，点“明天早上”就是明天早上发送，不会再往收件人栏里打入一个字母。

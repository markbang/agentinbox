A patch on 0.0.5 for what the redesigned client got wrong on a real phone and on a wide window: invisible titles, the band above every page, the wrong type, two spinners, the end of a list under the tab bar, and a few loose ends in keys, sheets and the composer.

## What's in 0.0.5.1

### Improved

- Sheets are at most 640 pt wide and centred on a wide window (a settings, compose or form sheet is a card, as on iPad) instead of stretching the full width.

### Fixed

- Every page shows its title again: the bar's compact title faded in from a scroll value nothing drove, so it stayed at zero opacity.
- **Android draws edge to edge again.** The content starts under the status bar,
  in the app's own background, with icons that follow the appearance: the native
  toolbar the navigation stack added over each page is gone (its light window
  colour was the white band, and it pushed every page 100 pt down).
- **The type face is the platform's.** Android draws Roboto for Latin and Noto
  Sans CJK SC for Chinese, windows Segoe UI, and the web follows the system, so
  glyphs are no longer a loose fallback; iOS's letter spacing now applies only
  where SF Pro is the font it was measured against.
- **One spinner.** The list's pull to refresh is the Cupertino indicator; the
  platform's teal Material spinner no longer appears beside the bar's.
- **The tab bar no longer covers the end of a list.** Settings and every other
  list stop above the bar instead of ending under it.
- API keys: a revoked key stays in the list as a greyed, unclickable row with the date it was revoked, as the server keeps it, instead of disappearing as if it were still usable.
- **The composer's schedule menu is above the keyboard.** Opening it dismisses the keyboard, so a tap on "Tomorrow morning" sends tomorrow morning instead of typing a letter into the To field.
